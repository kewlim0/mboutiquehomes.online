连接不上后台服务

这个页面需要后端程序才能读写数据库。请确认：

  1. 在项目文件夹运行了 npm start（本地数据库要先 npm run dev:db）。
  2. 用 http://localhost:3000/admin 打开，不要用 VS Code 的 Live Server（5500 端口）或直接打开 HTML 文件。
  3. 如果连的是线上数据库，SSH 隧道（npm run tunnel）要保持开着。
